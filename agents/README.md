## Conventions

- Frontmatter follows the L0 agent format (`name`, `role`, `status`, `tier`, `model`, `version`, `last_reviewed`, `description`, `examples`, `lifecycle`). Hired agents also declare `handoff_to` and `handoff_from`.
- Files are dispatched only by PM. Full roster, aliases and owned skills: `../AGENTS.md`.
- English only. Adding, re-tiering or retiring an agent goes through PM and updates `../AGENTS.md` in the same change.
