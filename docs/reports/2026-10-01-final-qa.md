## Independent code review

An independent review of the new stage and eval code (`/code-review`, medium) reported 12 findings. All were fixed with regression tests in `test/review-fixes.test.ts`: interview stage status overwritten, unresumable run after a late failure, privacy/terms consistency never checked in code, non-deterministic C2 finding ids (and envelope hash), unfixable document-level style findings, drafter missing facts dropped, skipped questions overwriting `not_applicable`, must-rule digest limited to drafted sections, unmeasured gate metrics passing silently, cross-document defects bypassing C2, a malformed clause file aborting the load, an invalid house-style pattern crashing C2.

## Findings

1. **Personal data in a committed capture index: resolved on 2026-10-01 (user decision).** `kb/jurisdictions/kr/clauses/_captures/index.json` held, as extracted headings of a public Lotte policy page, two named individuals, a corporate e-mail address and their phone numbers. By the user's instruction they were replaced with `홍길동`, `privacy@lotte.net` and `010-0000-0000` (five lines; the institutional numbers of public agencies and company switchboards stay). `captureIndexSha256` in `clauses/index.json` and `manifest.json` was updated to the new file hash, and `scripts/validate-clauses.ts` passes. The raw captures on the original PC still hold the real values; do not rebuild the index from them without redacting again. Note: the deny-list in `scripts/validate-clauses.ts` (`NAMES`) contains real surnames and given names so that residual names are detected; it is a deliberate exception and should stay out of any published copy.
2. **No clause is vetted and no house-style rule is approved.** The clause-first path and the house-style checks are implemented and tested, but inactive in production until the privacy-domain-expert vets clauses and the user approves rules.
3. **11 clause variables have no interview slot** (document metadata and a few facts). Nine clause files are skipped by the matcher. Pinned in `test/kb-integrity.test.ts`.
4. **C2 covers generic AST checks only.** The rule packs' `check.expr` pseudo-DSL targets a typed section model that the block-based AST does not have, so those rules are covered by the R7 auditor, not evaluated deterministically.
5. **Masking is off by default** (user decision 2026-09-30). Interview and form text reaches the models sanitized and fenced but unmasked. `--masking basic` restores masking before any model call.
6. `packages/cli` is an empty stub; the scripts in `scripts/` are the command line.
