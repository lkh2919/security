# 시연 대본 (5분) — 데모데이 2026-10-29~30

목표: 심사 4개 항목(업무 효과성 30, AI 활용 적합성 30, 완성도 20, 전사 적용 20)을 5분 안에 모두 보여 준다.
원칙: 실시간 크롤링은 하지 않는다. 저장된 결과로 시연하고, 라이브 구간마다 대비용 녹화본을 둔다.

## 준비 (시연 전날)

1. 시연 PC에서 대시보드를 만든다.
   `bun scripts/build-dashboard.ts --config config/orgs/example/org.json` → `runs/example/dashboard/index.html`을 브라우저로 연다(서버 불필요).
2. 평가 게이트를 실행해 통과 화면을 확인한다: `bun scripts/eval-gates.ts`
3. 라이브 구간(0:40–2:00)의 녹화본을 만든다. 네트워크·사용량 한도 문제 시 녹화본으로 전환.
4. 발표 자료 마지막 확인: 시범 측정 숫자를 `[측정 예정]` 자리에 넣었는지, 측정하지 못했다면 "목표치"로 표시했는지.

## 예상 질문과 답

- **법률 자문인가?** 아닙니다. 모든 결과는 참고용이며 최종 판단은 정보보호실·법무가 합니다. 확정 알림은 도메인 전문가가 규칙을 검증한 뒤에만 나갑니다.
- **다른 회사 사이트를 긁어도 되나?** 처리방침은 법에 따라 공개되는 문서이고(개인정보 보호법 제30조제2항), robots.txt를 지키며 하루 1회만 받습니다. 원문은 저장소에 두지 않고 해시만 보관합니다.
- **숫자가 합성 데이터 기준 아닌가?** 맞습니다. 게이트는 합성·골든 데이터 기준이고, 실제 업무 효과는 정보보호실 시범 측정으로 보여 드립니다(n과 "시범" 표기).
- **비용은?** 처리방침 1건 모델 점검이 정가 환산 약 0.3달러이고, Claude Code 구독으로 돌리면 별도 API 비용이 없습니다.
- **금융 계열사는?** 1차에서는 신용정보법 등 개정을 감시만 하고, 해당 조항은 사람 검토로 넘깁니다.
