7. **Row 3 spike outcomes.** Full detail: [`docs/reports/2026-09-29-law-spike-report.md`](../reports/2026-09-29-law-spike-report.md).
   - The 2026 PIPA amendment (Act 21445, promulgated 2026-03-10, effective 2026-09-11) is verified. The 10% turnover cap applies only to repeat, 10M+ victim, or ignored-corrective-order cases. The general cap stays at 3%.
   - KFTC 제10023호 is the e-commerce standard terms (rev. 2015-06-26).
   - The effective dates of Art. 35-2 and Art. 37-2 are verified.
   - Guideline 2026.4 is still the newest edition (pipc.go.kr BS217 nttId 12018, dated 2026-04-23).
   - Future-dated changes (2027-03-09 AI-development disclosure) must be modeled as effective-dated rules.
8. **Risks recorded.**
   - The law.go.kr OC key requires a registered IP or domain (1-2 days approval). The freshness watcher runs from a registered machine in Phase 1.
   - Portable use on any PC cannot call the API. It needs a bundled snapshot plus an offline drift warning. This is deferred with the portable zip.
   - An unregistered OC returns HTTP 200 with an error body. Scripts must parse the body.
   - Old ftc.go.kr URLs return a 200 homepage. Detect this by content.
   - Git Bash on Windows garbles Korean curl arguments. Send UTF-8 percent-encoded queries.
